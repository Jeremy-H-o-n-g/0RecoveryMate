# RecoverMate Project Plan

Authoritative baseline: Jeremy Hong's RecoverMate proposal.

Core: interactive front/back body map; six body regions; 2–3 reviewed exercises per region; cards; video, steps, timer, completion feedback; responsive cyber-sport visual system; static deployment; 10-student formative study.

Refinements: professional content review, provenance/licensing, captions/transcripts, build-time validation, WCAG-oriented interaction, non-diagnostic safety boundaries, offline demo, reproducible research.

Out of scope: diagnosis, treatment, accounts, production health data, public uploads, database, individualized recommendation.
