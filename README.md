# RecoverMate Kickoff Starter

This starter contains the project-state system, bounded session prompts, sample schemas, and preparation files. It intentionally does not implement future sessions.

## Baseline & Requirements (S01)
- Requirements ledger: [`docs/baseline-ledger.md`](docs/baseline-ledger.md)
- Traceability matrix: [`docs/Traceability.md`](docs/Traceability.md)
- S01 review evidence: [`docs/traceability-review-S01.md`](docs/traceability-review-S01.md)

## Start

1. Complete the 3-hour environment module in the Kickoff Preparation Guide.
2. Open this folder as the repository root.
3. Read `TASKS.md`, `docs/ProjectPlan.md`, `docs/Architecture.md`, and `prompts/GlobalEngineeringContract.md`.
4. Begin with S01 only.
5. Update `TASKS.md` in place; never overwrite its history for each session.

## Safety

RecoverMate provides general educational recovery/warm-up guidance only. It does not diagnose, treat, or replace qualified professional advice. Publish no exercise until its source, rights, professional review, captions, transcript, and stop signals are complete.
