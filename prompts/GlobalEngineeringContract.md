# RecoverMate Global Engineering Contract

- Inspect `README.md`, `TASKS.md`, relevant design documents, current code, and existing tests before editing.
- Summarize current state and create a checkpoint.
- Implement exactly one approved session; keep the project runnable after each small step.
- Preserve working behavior and unrelated user changes.
- Run tests and manual checks; report exact results and changed files.
- Keep secrets out of code, screenshots, samples, documents, and client bundles.
- Never fabricate content approval, licensing, research participants, test results, or manual evidence.
- RecoverMate is non-diagnostic general guidance. Unreviewed content must remain blocked.
- Stop when the current session passes; do not begin the next session.
